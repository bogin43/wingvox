# ---------- macOS ----------

# mlx-whisper itself is NOT listed here: install.sh installs it separately
# with --no-deps, because its declared dependency set drags in torch
# (106MB), llvmlite (39MB), scipy (19MB), numba, sympy and networkx --
# ~176MB that stt_mac.py's code path never touches. torch is never imported
# at all, and numba/scipy are only reached by mlx_whisper's unused
# word-timestamps feature, which flow.py fakes out with sys.modules stubs
# (flow.py:36). The installer used to download all of it and then uninstall
# it again on every single install.
#
# The lines below are mlx-whisper's remaining, genuinely-needed
# dependencies, spelled out because --no-deps means pip won't resolve them.
# If a future mlx-whisper release imports something new, it fails loudly
# with an ImportError rather than silently degrading.
#
# Installing by hand? Use:
#   pip install -r requirements.txt && pip install --no-deps mlx-whisper
mlx; sys_platform == "darwin"
more-itertools; sys_platform == "darwin"
tiktoken; sys_platform == "darwin"
tqdm; sys_platform == "darwin"
huggingface_hub; sys_platform == "darwin"

# dependencies (modulegraph, macholib) correctly in this environment.
